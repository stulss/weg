# Backend (미구현)

현재 plen은 정적 프론트엔드만 있는 브라우저 기반 앱입니다. 이 디렉터리에는 실행 가능한 API 서버나 데이터베이스 코드가 아직 없습니다. 기존 화면·스타일·브라우저 동작은 `frontend/`에서 관리합니다.

향후 백엔드를 추가할 때에는 프론트엔드와 API를 분리하고, 서버 내부는 MVC 역할에 따라 나누는 방향입니다. 프레임워크와 데이터베이스는 아직 선택하지 않았습니다.

```text
backend/
└── src/
    ├── controllers/  # 요청 검증, 애플리케이션 흐름, 응답 처리
    ├── models/       # 도메인 규칙과 데이터 접근 모델
    ├── views/        # 서버가 제공할 화면 또는 표현 계층 (필요한 경우)
    └── routes/       # URL과 컨트롤러 연결
```

이 구조는 다음 기능을 서버로 옮기기 전에 API 계약과 저장 범위를 정하기 위한 계획입니다. 현재 지원 자료와 경험 카드는 브라우저의 `localStorage`에만 저장됩니다. 백엔드가 준비되기 전까지 서버 저장·계정·기기 간 동기화가 된다고 안내하지 않습니다.
