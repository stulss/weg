# plen

여러 회사에 지원하는 취준생을 위한 브라우저 기반 취업 준비 웹앱입니다.

## 실행 및 구조

브라우저에서 `frontend/index.html`을 열어 실행합니다. 실제 화면 코드는 `frontend/`에 있습니다. `backend/README.md`는 향후 백엔드 MVC 계획이며, 실행 가능한 API 서버와 DB는 없습니다.

## 주요 기능

- **경험 카드:** 경험 등록·수정·삭제 및 브라우저 저장. v2 화면에서는 STAR, 날짜, 반복 관측 일수, 바깥 증거와 태그를 기록합니다.
- **채용공고 키워드:** 규칙 기반 사전·표현 분석. 입력한 공고를 외부 전송하지 않고 브라우저에서 분석합니다.
- **팩트 시트 → 1인칭 초안:** 선택한 카드로 팩트 시트를 작성하고 사용자가 확인한 뒤 규칙 기반 초안을 편집합니다. 선택 경험 밖의 임의 서술은 자동으로 완벽히 막을 수 없으므로 사용자가 원자료를 대조해야 합니다.
- **9개 검사:** 키워드, 카드에 없는 숫자, 글자 수, 날짜·STAR, 금지 형용사, 첫 문단 강점, 바깥 증거, 기록 보완 표기, 직접 완성 상태를 점검합니다. 휴리스틱이며 사실 인증이 아닙니다.
- **리추얼 CSV:** 미리보기·날짜 변환·중복 제거·경험 카드 연결·기록 통계 기능이 있습니다.
- **이력서:** 기본 정보·프로필·경력·프로젝트·학력·기술·역량·자격·수상 항목 작성, 미리보기 및 내보내기를 지원합니다.
- **회사별 지원 자료:** 공고와 입력 내용을 회사별로 저장하고 진행 상황을 관리할 수 있습니다.

## 자소서 작성 사용 흐름

1. 경험 카드에 실제 사실과 출처를 입력하고, 채용공고 탭에서 공고를 붙여넣어 키워드를 검토합니다.
2. 자소서 작성 탭에서 사용할 카드(최대 3개)를 선택하고 문항·글자 수 제한을 입력합니다.
3. 팩트 시트를 생성해 문장과 출처, 기록 공백 표기를 확인·수정합니다. 선택한 모든 카드가 포함되어야 하며, 수정 후 다시 확인합니다.
4. 확인된 팩트 시트에서 규칙 기반 1인칭 초안을 만들고, 직접 사실과 문장을 검토·편집합니다.
5. 오른쪽 9개 검사 결과를 확인합니다. 기록 공백 표기 검사는 실패하면 저장을 차단합니다. 사용자가 직접 수정하고 완료 체크를 해야 새 기록으로 저장할 수 있습니다.

현재 초안 기능은 AI 생성이 아니라 템플릿·규칙 기반이며, MVC 백엔드와 AI Gateway는 구현되지 않았습니다. 규칙 검사 통과만으로 경험의 진위나 글의 적합성이 보증되지는 않습니다.

## 검사와 검증 상태

Node.js가 설치된 환경에서 다음 명령으로 자동 검사를 실행할 수 있습니다.

```sh
node checks.js
```

검사는 CSV 처리, 초안 생성·정적 화면 연결 확인, 9개 검사 각각의 정상 사례와 실패 사례를 포함합니다. 이 프로젝트를 수정한 환경에서는 명령 실행 결과를 확인하지 않았습니다. 브라우저 수동 확인도 수행되지 않았습니다.

**실제 공고 3건 완성 기준 검증은 미실행입니다.** `plan_v2.md`의 테스트 표를 채우려면 실제 채용공고 원문 3건, 그에 연결할 본인의 실제 경험 카드, 문항과 글자 수 제한이 필요합니다. 예시 데이터로 통과라고 표시하지 않습니다.

## 저장과 개인정보

자료는 브라우저 `localStorage`에 보관되며 동기화나 서버 백업은 없습니다. 공용 기기에서는 저장을 피하고, 경험 카드 및 리추얼에 포함된 본인·동료 개인정보를 입력하거나 공유할 때 주의하세요.

## 주요 파일

- `frontend/index.html`: 화면과 스크립트 연결
- `frontend/assets/js/career-core.js`: 경험·공고 키워드·팩트 시트·기본 9개 검사 로직
- `frontend/assets/js/career-ui.js`: 경험/공고/초안 화면 이벤트 및 9개 검사 화면 갱신
- `frontend/assets/js/draft-workflow-core.js`: 팩트 시트 검증과 1인칭 규칙 변환
- `frontend/assets/js/draft-inspection-core.js`: 상세 9개 검사 로직을 `career-core.js` API에 연결
- `frontend/assets/js/draft-stage4.js`: 저장된 초안 기록 UI. 현재 `career-ui.js`가 기록 화면을 자체 생성하므로 사용하지 않는 보조 스크립트
- `frontend/assets/js/draft-ui-guard.js`: 보조 저장 가드 및 진행 상태 표시
- `checks.js`: Node.js 자동 검사
- `plan_v2.md`: 현재 계획 및 실제 자료 완성 기준 표
- `remaining-plan.md`: 남은 단계와 확인 상태
